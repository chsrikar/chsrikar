## 🔧 TROUBLESHOOTING

### If profile doesn't appear:

- Repository name must EXACTLY match username
- Repository must be PUBLIC
- README.md must be in root directory (not in subfolder)
- File must be named README.md (case-sensitive)

### If images don't load:

- Check file paths are relative: `assets/file.svg` not `/assets/file.svg`
- Verify files are committed and pushed
- Check SVG syntax is valid

### If stats don't show:

- Replace [username] with actual username in URLs
- Stats may take hours to generate for new accounts
- Ensure your repos are public

### If animations don't work:

- GitHub supports SMIL animations (they should work)
- Check browser supports SVG animations
- Verify SVG files aren't corrupted
